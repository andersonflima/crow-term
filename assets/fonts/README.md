# Crowquill Mono — unmodified bundled faces

Family: **Crowquill Mono**. “Crow Mono” is not used as a renamed family.
The four TTF files are unmodified copies from the author's local source checkout
of [andersonflima/crowquill-mono](https://github.com/andersonflima/crowquill-mono),
revision `200381d12e39ba6377c42adedfed0c83425d1e7f`, `dist/`, captured 2026-10-28.

Licensed under **SIL Open Font License 1.1**; the complete notice is in [OFL.txt](OFL.txt).
The upstream is an Iosevka derivative with contextual keyword-bold (`calt`),
programming ligatures and italic faces. The font cannot parse language semantics;
keywords can also receive contextual bold inside strings/comments. Preserve
the family, license and attribution when redistributing. These are fonts, not
system font installers; Crow Term must load them directly or use an explicitly
user-installed matching family. Emoji coverage/fallback belongs to the renderer
and system fallback fonts, not to these four files.
