# Public appearance assets

The original theme is **Crowquill Ink**, from
[andersonflima/crowquill-theme](https://github.com/andersonflima/crowquill-theme),
revision `4b75faf2228e3768aa4d8168f8fb6ab6540253a7`, inspected 2026-10-28.
Its MIT notice is retained in [theme-license.txt](theme-license.txt).
“Crow Ink” is not asserted to be a separate or renamed upstream project.

`crowquill-example.toml` is an explicit, public allowlist inspired by the owner's
terminal profile: 18-point Crowquill Mono, grayscale ANSI, background `#111111`,
foreground `#EAEAEA`, selection `#444444`, white cursor. It is **not** an entire
dotfile export. The original theme's base is `#0A0A0A`/`#B8B8B8` with `#2A2A2A`
selection; the distinction is intentional. No account, SSH, history, environment,
machine path, token, private title helper or agent hook is included.

Font attribution, exact file hashes and limitations are in [fonts/README.md](fonts/README.md).
